## 二、Hook 补全详情

设计文档要求保留的初版 Hook（共 18 个），本次补全后全部到位：

### 2.1 新增 Hook 定义（`Hook.cs`）

```
BeforeCombatStart(CombatState combat)
AfterCombatEnd(CombatState combat)
BeforeTurnStart(CombatState combat)
AfterTurnStart(CombatState combat)
BeforeTurnEnd(CombatState combat)
AfterTurnEnd(CombatState combat)
BeforeCardMovedPile(CardModel card, CardPile from, CardPile to)
AfterCardMovedPile(CardModel card, CardPile from, CardPile to)
BeforeCreatureDied(Creature creature)
AfterCreatureDied(Creature creature)
```

### 2.2 调用点

| Hook | 调用位置 | 说明 |
|------|---------|------|
| `BeforeCombatStart` | `CombatManager.StartCombatAsync` 开头 | 战斗正式开始前 |
| `AfterCombatEnd` | `CombatManager.CheckWinConditionAsync` 中 `CombatEnded` 事件之后 | 胜负判定、战斗结束后 |
| `BeforeTurnStart` | `StartPlayerTurnAsync` / `ExecuteEnemyTurnAsync` 开头 | 玩家/敌人回合开始前 |
| `AfterTurnStart` | `StartPlayerTurnAsync` 末尾 | 抽牌、Roll意图完成后 |
| `BeforeTurnEnd` | `EndPlayerTurnAsync` 中 `DiscardHands` 之前 | 玩家回合结束前 |
| `AfterTurnEnd` | `EndPlayerTurnAsync` / `EndEnemyTurnAsync` 末尾 | 回合切换前 |
| `BeforeCardMovedPile` | `CardPile.Add` 中，从旧 pile 移除前 | 用于遗物/效果拦截移动 |
| `AfterCardMovedPile` | `CardPile.Add` 中，移动完成后 | 用于监听牌堆变化 |
| `BeforeCreatureDied` | `Creature.SetCurrentHp` 中 `Died?.Invoke` 之前 | 死亡前触发 |
| `AfterCreatureDied` | `Creature.SetCurrentHp` 中 `Died?.Invoke` 之后 | 死亡后触发 |

> 注意：`BeforeCardMovedPile` / `AfterCardMovedPile` 在 `CardPile.Add` 中以 `_ = Hook.xxx(...)` 方式调用，因为 `CardPile.Add` 本身不是异步方法。当前 Hook 为空壳，同步返回 `Task.CompletedTask`，无性能影响。若后续 Hook 需要异步，需在阶段3/4时统一重构 `CardPile` 的调用链路。

## 五、为阶段3打下的基础

1. **Hook 系统完整**：阶段3的遗物、事件、Power 触发有了全生命周期接入点。
2. **事件无泄漏**：`CombatManager.Reset()` 在视图销毁时被可靠调用，多场战斗（Run 循环）不会累积旧事件。
3. **能量变化可观测**：`EnergyChanged` 事件已就绪，阶段3的任何效果改能量都能自动刷新 UI。
4. **卡牌移动幂等**：`MoveCardToResultPile` 增加了重复移动保护，后续复杂卡牌效果更安全。
5. **表现反馈闭环**：敌人受击有视觉反馈（`PlayHitReaction`），Intent 显示已修复，玩家能获得完整战斗信息。
