# 词条

## 定义

[[玩家卡]] 或 [[怪物卡]] 拥有的特殊效果/被动能力的统称。[[游戏开发项目/九宫牌局/04-技能/技能系统]] 是词条的具体实现形式。

## 用法

"词条"一词多用于泛指卡牌的特殊机制，而具体的词条以 "技能" 命名并定义。例如 [[游戏开发项目/九宫牌局/01-机制规则/先攻]]、[[庇佑]]、[[复仇]] 等都是具体的词条/技能。
