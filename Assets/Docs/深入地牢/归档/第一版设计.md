# 设计灵感
迷失之径（GODOT开发），魔塔与星陨传说

# 设计核心
在狭小的九宫格内展开的肉鸽卡牌冒险，靠着翻动卡牌来营造策略性

# 九宫格战场

| 格1 | 格2 | 格3 |
|:---:|:---:|:---:|
| **格4** | **格5** | **格6** |
| **格7** | **格8** | **格9** |

- 战场为 **3×3 九宫格**，共九个**格子**。命名规则：第一排从左至右为 **格1、格2、格3**；第二排为 **格4、格5、格6**；第三排为 **格7、格8、格9**。
- [[玩家卡]]总是在格8出生
- 进入新战斗房间时，将[[地城牌组]]里的[[卡牌]]以正面朝下随机分布到九宫格上，保证除了[[玩家卡]]所在格，其他格子上都有至少一张[[卡牌]]

# 基础游戏规则
- 玩家需要清理完房间所有[[怪物]]才能进入下一个[[房间]]
- [[玩家卡]]临近格子上的[[卡牌]]会翻转到正面朝上，如果[[格子]]上不止一张[[卡牌]]只有最上方的[[卡牌]]会翻转
- [[玩家卡]]可以拖动，但只能拖动到空白格进行移动或拖动到正面朝上的卡牌上进行互动
- 互动不改变玩家所处格位置
- 当互动使得[[卡牌]]从[[格子]]上[[移除]]且其下方还有其他[[卡牌]]时，将下方最上方的[[卡牌]]翻转
# 卡牌类型
- [[玩家卡]]：代表着玩家角色，拥有血量，防御，攻击三个属性，可能带有词条，可拖动
- 怪物卡：代表着敌对角色，拥有血量，防御，攻击三个属性，可能带有词条
- 宝箱卡：可以开出[[游戏开发项目/卡牌地下城/卡牌地下城_正式设计/01-核心定义/遗物]]，装备于[[游戏开发项目/卡牌地下城/卡牌地下城_正式设计/01-核心定义/遗物]]格
- 金币卡：可以获得[[金币]]
- 道具卡：可以被拖动到[[道具牌格]]保存，并从[[道具牌格]]拖动使用
- 机关卡：随机行动伤害[[怪物卡]]和[[玩家卡]]，摧毁后生效，不可拖动

# 发牌规则
- 格8在战斗开始只会拥有[[玩家卡]]
- 格7，格5，格9
# 房间类型
- 商店：购买属性，道具，遗物
- 休息：恢复和强化属性
- 战斗：地城牌组只会出现普通怪物卡
- 精英战斗：地城牌组只会出现普通怪物卡和一张精英怪物卡
- 层主战斗：地城牌组只会出现普通怪物卡和一张层主怪物卡



# 战斗关卡流程
1. 进入新战斗房间时，将[[地城牌组]]里的[[卡牌]]以正面朝下随机分布到九宫格上，保证除了[[玩家卡]]所在格，其他格子上都有至少一张[[卡牌]]
2. 玩家一直与正面朝上的[[卡牌]]进行互动，直到房间中没有[[怪物]]
3. 当[[房间]]中没有[[怪物]]后，出现三个房间类型供玩家选择（层主战斗房除外，只提供一个通往下一层的房间）

# 伤害结算流程
- 在双方都没有先攻词条的情况下，总是玩家先造成[[伤害]]
- 在双方都有先攻词条的情况下，总是玩家先造成[[伤害]]
- 拥有先攻词条的一方，总是先造成[[伤害]]
- 如果伤害导致一方死亡，则死亡的一方无法造成伤害

# 行动规则
- 玩家每移动和交互一次均视为行动一次
- 玩家拖动和使用道具卡不视为行动
# 界面
- 正中间九宫格为作战场地
- 九宫格下方额外的三个格子最左侧为主动遗物格，右侧两个为[[道具牌格]]
- 九宫格右侧额外六个格子是遗物[[格子]]
- 九宫格左侧部分显示玩家的属性，血量，攻击，防御，词条，金币，头像
