
# 基础规则
- 每层一共9个[[地图节点]]，其中第1个固定为[[奖励房]]，第8个固定为[[餐厅]]，第9个固定为[[层主]]战斗
- 第1[[地图节点]]-第3[[地图节点]]胜利后可选房间类型只有**金币房**，**宝箱房**，**属性房**
- 第4[[地图节点]]-第6[[地图节点]]胜利后可选房间类型只有**金币房**，**宝箱房**，**属性房**，**商店**，**精英战斗**
- 第7[[地图节点]]胜利后**固定进入[[餐厅]]**，无需选择

# 怪物出现规则
> 分配算法：按各等级列出的数量范围随机取值，若各级别数量之和小于 9+X，则从最高等级开始依次补足，直到总数等于 9+X（X 为当前层数）。

- 第1[[地图节点]]：6~7只等级1怪物，2~3只等级2怪物，总计等于9+X只
- 第2[[地图节点]]：5~6只等级1怪物，3~4只等级2怪物，总计等于9+X只
- 第3[[地图节点]]：2~3只等级1怪物，3~4只等级2怪物，2~3只等级3怪物，总计等于9+X只
- 第4[[地图节点]]：1~2只等级1怪物，3~4只等级2怪物，3~4只等级3怪物，总计等于9+X只
- 第5[[地图节点]]：1只等级1怪物，3~4只等级2怪物，3~4只等级3怪物，1只等级4怪物，总计等于9+X只
- 第6[[地图节点]]：0~1只等级1怪物，2~3只等级2怪物，3~4只等级3怪物，1~4只等级4怪物，总计等于9+X只
- 第7[[地图节点]]：1~2只等级2怪物，3~4只等级3怪物，3~5只等级4怪物，总计等于9+X只
- 第9[[地图节点]]：1~2只等级2怪物，3~4只等级3怪物，3~5只等级4怪物，总计等于9+X只
