# 设计灵感

> **核心灵感**：迷失之径，魔塔 × 星陨传说（Meteorfall）

---

## 一、设计核心

**一句话定义**：在狭小的 **3×3 九宫格** 内展开的肉鸽卡牌冒险。  
**核心机制**：通过**翻动卡牌**与**拖动卡牌**营造空间策略性，在有限格子里做出最优决策。

## 三、基础游戏规则

### 3.1 胜利条件
- 清理当前房间内的所有[[怪物]]后，方可进入下一个[[房间]]。
- 击败最后一层（第3层）的层主后，游戏通关。

### 3.2 视野与揭示
- [[玩家卡]]**临近格子**（正交相邻，即上下左右四格，不含对角线）上的[[卡牌]]会**自动翻转**为正面朝上，且翻转后**不会恢复**为背面朝下。
- 若一个[[格子]]上叠有多张[[卡牌]]，仅**最上方**的一张会被翻转。


### 3.3 移动与互动
- **可拖动**：[[玩家卡]]可以被拖动。
- **移动**：只能拖至**空白格**。
- **互动**：只能拖至**正面朝上的卡牌**上。**正面朝下**的[[卡牌]]不参与任何互动（无论什么类型的卡牌，怪物卡，玩家卡，机关卡，道具卡等等卡牌，只要是正面朝下就相当于暂时不存在）。[[玩家卡]]只能与单格的单张正面朝上的[[卡牌]]互动
- **位置不变**：互动时，[[玩家卡]]**不改变**自身所处格子的位置；即使目标卡牌被移除，玩家卡也仍停留在原格。

### 3.4 卡牌堆叠处理
- 当互动导致某张[[卡牌]]从[[格子]]上**移除**，且下方卡牌处于玩家卡[[玩家卡]]**临近格子**（正交相邻，即上下左右四格，不含对角线），则将其自动翻转至正面朝上，且该卡牌「被翻开时」的效果**立即结算**。
- 堆叠的卡牌只有最上面那张能够正面朝上，其他卡牌都保持正面朝下
- 如果有新卡牌堆叠在了正面朝上的卡牌上方时，下方卡牌自动翻转至正面朝下

## 四、卡牌类型

| 类型          | 属性       | 特性                   | 互动方式                                                  |
| :---------- | :------- | :------------------- | :---------------------------------------------------- |
| **[[玩家卡]]** | 血量、防御、攻击 | 可能带有词条               | **可拖动**                                               |
| **[[怪物卡]]** | 血量、防御、攻击 | 可能带有词条               | 通过拖动[[玩家卡]]至其上进行互动战斗                                  |
| **[[宝箱卡]]** | —        | 可开出[[遗物]]            | 开启后装备至[[遗物]]格                                         |
| **[[金币卡]]** | —        | 获得[[金币]]             | 将[[玩家卡]]拖动到金币卡上，获得50金币并移除                             |
| **[[道具卡]]** | —        | 一次性或有限次数效果           | **可拖动**至[[道具牌格]]保存；也可从[[道具牌格]]拖出使用                    |
| **[[机关卡]]** | —        | 对[[怪物卡]]和[[玩家卡]]造成伤害 | **不可拖动**；玩家可拖动[[玩家卡]]至机关卡上进行互动战斗，各机关具体触发时机和效果以机关卡描述为准 |

## 六、发牌规则

> **[[地城牌组]]**：当前房间用于生成所有卡牌的临时牌库。进入新房间时，根据房间类型组建地城牌组；房间结束后地城牌组清空。

- 确定房间类型，按房间类型提供的[[卡牌]]来组建[[地城牌组]]
- 将所有卡牌**正面朝下**随机分布至除**格8**（玩家所在格）之外的其他格子上，保证每个格子上至少有一张[[卡牌]]，尽可能均分到每个格子


## 七、战斗关卡流程

1. **房间初始化**：进入新战斗房间，按发牌规则将[[地城牌组]]的[[卡牌]]正面朝下随机分布至九宫格。
2. **探索与战斗**：玩家持续与正面朝上的[[卡牌]]进行互动。
3. **清场判定**：当房间中不存在任何[[怪物]]时，战斗结束。
4. **路线选择**：战斗结束后，旧卡保留在原地；出现**两~三个房间类型**供玩家选择，以正面朝上的卡牌形式出现在空格子上。若无空格子，则挤开旧卡使其堆叠至其他格子以腾出空位。将[[玩家卡]]拖动到想进入的房间类型上即可进入。
   > ⚠️ **例外**：层主战斗房结束后，**仅提供唯一一个**通往下一层的房间；第7节点战后固定进入[[餐厅]]，无需选择。

> **非战斗房（餐厅）流程**：餐厅内无怪物，不适用清场判定。进入后直接在空格子出现通往下一节点（层主战斗房）的入口卡，玩家自由与食品卡/导师卡互动完毕后，拖动[[玩家卡]]至入口卡即可进入下一场。

---

## 八、伤害结算流程

标准结算流程：无先攻时，玩家先对目标造成伤害；若目标未死亡，则目标进行反击造成伤害。拥有先攻的一方优先造成伤害。

> **优先级规则**：先攻词条 > 玩家默认优先

| 情境     | 结算顺序                                                                   |
| :----- | :--------------------------------------------------------------------- |
| 双方均无先攻 | **玩家先**造成伤害                                                            |
| 双方均有先攻 | **玩家先**造成伤害                                                            |
| 一方有先攻  | **先攻方**先造成伤害                                                           |
| 伤害致死   | 死亡的一方**无法造成伤害**；若双方同时受到致命伤害，则双方同时死亡(如果玩家卡互动先造成足以击杀怪物卡的伤害，则这次怪物卡不会造成伤害) |

---

## 九、失败与存档
- 玩家血量归零时，**游戏结束**，本局进度清空。
- 若玩家与房间最后一只怪物同时死亡，也算**游戏结束**。
- 支持中途存档，可在层间（路线选择界面）退出并保存当前进度。

## 十、行动规则

> **玩家行动**：[[玩家卡]]完成一次有效的**移动**或**互动**（拖动至空白格或正面朝上卡并结算完毕）。

| 行为 | 是否计为行动 |
|:---|:---:|
| 玩家移动（拖至空白格） | ✅ 是 |
| 玩家互动（拖至正面朝上的卡牌） | ✅ 是 |
| 玩家拖动[[道具卡]] | ❌ 否 |
| 使用[[道具卡]] | ❌ 否 |
| 从[[道具牌格]]拖出道具卡至场上 | ❌ 否 |
| 将道具卡收入[[道具牌格]] | ❌ 否 |

> 玩家必须持续行动，没有跳过回合的选项。
