

# 玩家卡与怪物卡的互动
- 玩家对怪物造成的伤害 = 玩家攻击 - 怪物防御
- 怪物对玩家造成的伤害 = 怪物攻击 - 玩家防御
- 伤害最低为 0，不可为负数
- 伤害结算流程参考：[[第二版设计]]

# 道具卡的互动
- [[道具卡]]拖动到[[玩家卡]]，[[机关卡]]和[[怪物卡]]上时产生卡牌描述的效果
- 所有与道具卡相关的行为均不计为玩家行动

# 玩家卡与机关卡的互动
- 玩家拖动[[玩家卡]]至[[机关卡]]上进行互动，双方互相造成伤害
- 玩家对机关造成的伤害 = 玩家攻击 - 机关防御（最低为0）
- 机关对玩家造成的伤害为**固定值**（机关基础攻击为0，故通常不对玩家造成伤害），不受玩家防御减免
- 机关血量归零时被摧毁，触发其摧毁效果
- 伤害结算流程参考：[[第二版设计]]
