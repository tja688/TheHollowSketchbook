# 刷新规则
- 初始遗物不会出现在遗物池里，无法通过宝箱开出
- 蓝色品质与金色品质遗物尚未设计

# 遗物数值规则
白色遗物：相当于2~4张[[属性提升卡]]的提升（成长性可达到蓝色遗物数值也可无上限但成长速度慢）
蓝色遗物：相当于4~8张[[属性提升卡]]的提升（成长性可达到金色遗物数值也可无上限但成长速度较慢）
金色遗物：相当于8~12张[[属性提升卡]]的提升（成长性数值也可无上限成长速度为快）

## 木剑 
- 属性：攻击+2

> **主动遗物使用方式**：所有主动遗物均为**点击使用**（点击后根据效果选择目标）。

# 白色主动遗物
## 法则魔杖 
- 属性：攻击+1
- 效果：可将任意一张牌（玩家卡除外），移动到任意一格
- 类型：主动，CD:每房间一次（进入新房间后重置使用次数）
- 品质：白色
## 无尽水袋 
- 属性：生命+4
- 效果：主动使用，恢复6点血量
- 类型：主动，CD:每房间一次（进入新房间后重置使用次数）
- 品质：白色
 ---
