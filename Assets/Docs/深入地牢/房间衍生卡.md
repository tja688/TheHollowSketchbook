# 食品卡
- 将[[玩家卡]]拖动到食品卡上，将[[玩家卡]]血量回满

# 宝箱卡
- [[普通宝箱卡]]：将[[玩家卡]]拖动到宝箱卡上，弹出选项框从三个遗物中选一个获得（65%概率是白色遗物，30%概率是蓝色遗物，5%概率是金色遗物）
- [[蓝色宝箱卡]]：将[[玩家卡]]拖动到宝箱卡上，弹出选项框从三个遗物中选一个获得（30%概率是白色遗物，50%概率是蓝色遗物，20%概率是金色遗物）
- [[金色宝箱卡]]：将[[玩家卡]]拖动到宝箱卡上，弹出选项框从三个遗物中选一个获得（0%概率是白色遗物，50%概率是蓝色遗物，50%概率是金色遗物）
- 蓝色品质与金色品质遗物尚未设计

# 导师卡
- 将[[玩家卡]]拖动到导师卡上，弹出选项框选择一张导师卡，使[[玩家卡]]获得对应词条；选择后移除其他[[导师卡]]
- 导师刺皮：赋予词条[[刺皮]]
- 导师硬皮：赋予词条[[硬皮]]
- 导师历战：赋予词条[[历战]]

# 商品卡
- 将[[玩家卡]]拖动到商品卡上，若金币足够则自动扣除并购买；金币不足时，玩家卡**无法拖动至商品卡上**
- 商店从以下列表中随机抽取4~6张商品卡（可重复）
- 50金币，攻击+1
- 50金币，防御+1
- 50金币，血量+2
- 30金币，随机道具卡
- 100金币，宝箱卡
