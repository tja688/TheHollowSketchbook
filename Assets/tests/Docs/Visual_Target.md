# 视觉目标文档 (Phase 00)

> 本项目不是在复刻 PS1 滤镜，而是在复刻"邪恶冥刻式不忠实复古"。

## 一句话目标

用现代 Unity 做一套非现代感的桌面卡牌渲染管线：
**低清、黑暗、暗部风格化、亮部保可读、UI 实体化。**

## 必须优先的核心机制

- [x] 低清画布（960×540 虚拟分辨率）
- [x] 黑场吞掉非关键信息
- [ ] 非 PBR fake lighting（RetroFakeLit）
- [ ] 卡牌双纹理结构（GravestoneCard）
- [ ] 暗部阈值 LUT（PosterizeWithThreshold）
- [ ] 脏暗角和颗粒（Vignette + Noise）
- [ ] 桌面实体 UI（倍率格、心蜡烛、魂瓶、遗物架）

## 默认不做

- 强顶点抖动
- 强仿射纹理扭曲
- 强扫描线
- 大面积 VHS glitch
- 高光滑 PBR 材质

## 风格判断标准

看到一个新特效时，判断它属于：
- **核心机制** → 低清、黑场、暗部 LUT、实体 UI
- **可选增强** → 轻镜头畸变、轻色散、轻颗粒
- **风格误区** → PS1 顶点抖动、强扫描线、VHS glitch、一键复古滤镜
